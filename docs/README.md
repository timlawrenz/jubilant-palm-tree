# Documentation Directory

This directory contains comprehensive documentation for the jubilant-palm-tree research project.

## 🚀 Project Status: PIVOTED TO PHASE 5

The project has executed a **major research pivot**. After Phase 4b demonstrated that GNNs suffer from the "Literal Value Bottleneck" (generating 0% valid syntax due to unrecoverable strings), we pivoted away from text-based generation. 

The new goal: **Neural Universal Machine — eradicate human syntax entirely**. We now generate adjacency matrices representing executable DAGs directly, using a Diffusion Transformer (DiT).
